# Joint Independence Testing for Latent Position Random Graphs

This repository contains the code used to reproduce the numerical experiments and real-data analysis presented in our paper, *Joint Independence Testing for Latent Position Random Graphs*.

## Code Organization

The `code/` directory contains the following scripts and notebooks:

### Simulation Experiments

- **Experiment 1A:** `sim_diff_M.py`
- **Experiment 1B:** `sim_diff_d0.py`
- **Experiment 1C:** `sim_diff_cov.py`
- **Experiment 1D:** `sim_diff_gamma.py`
- **Experiment 1E:** `sim_diff_c.py`
- **Experiment 2:** `compare_power_and_time.py`

### Real-Data Analysis

- **Experiment 3:** `GHSIC_real_data.ipynb`

  The real-world dataset is publicly available on [OpenNeuro (ds003020, version 2.0.2)](https://openneuro.org/datasets/ds003020/versions/2.0.2/).

### Visualization

- `GHSIC_plot.ipynb`: Generates the figures from the simulation results.

## Reproducibility

Run the corresponding scripts or notebooks to reproduce the results reported in the paper.
